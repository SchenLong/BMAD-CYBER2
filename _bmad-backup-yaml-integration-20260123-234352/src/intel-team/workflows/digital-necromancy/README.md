# Digital Necromancy

**Historical digital footprint recovery and timeline reconstruction**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Individual Investigation |
| **Duration** | 1-2 hours |
| **Steps** | 4 |
| **Primary Agent** | Resolver (Domain Intel) |
| **Supporting Agents** | Echo, Shadow, Probe |

## Purpose

Recover deleted, historical, or obscured digital presence:
- Deleted content recovery
- Historical presence reconstruction
- Timeline building
- Digital archaeology

## Steps

1. **Archive Discovery** (Resolver) - Wayback Machine, cached content
2. **Social Archaeology** (Echo) - Deleted posts, old profiles
3. **Breach History** (Shadow) - Historical breach exposure
4. **Timeline Assembly** (Probe) - Chronological reconstruction

## Outputs

- Historical digital timeline
- Recovered content inventory
- Identity evolution map
- Gap analysis

## Usage

```
/intel-team:domain-intel-specialist
> Digital Necromancy
```
