# Ethical Dilemma Resolution Workflow

## Overview

An 8-step workflow for navigating complex ethical dilemmas through structured multi-perspective analysis and principled resolution. Helps leaders make difficult decisions that balance competing values, stakeholder interests, and organizational responsibilities.

## Ethical Frameworks Applied

- Utilitarian analysis (greatest good)
- Deontological ethics (duty-based)
- Virtue ethics (character-based)
- Care ethics (relationship-based)
- Justice/fairness principles
- Rights-based analysis

## Coverage

- **Dilemma Framing**: Core tension, competing values, constraints
- **Stakeholder Values**: Affected parties, their values and expectations
- **Ethical Framework**: Multiple lens analysis
- **Perspective Analysis**: Historical archetype viewpoints
- **Option Evaluation**: Trade-offs, consequences, precedents
- **Decision Synthesis**: Principled resolution with rationale
- **Implementation**: Communication, monitoring, adjustment
