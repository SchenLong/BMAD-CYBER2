# Strategic Planning Session Workflow

## Overview

An 8-step workflow for long-term strategic planning incorporating diverse strategic philosophies. Helps leadership teams develop comprehensive strategic plans with multiple perspective input.

## Workflow Structure

```
strategic-planning-session/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-environmental-scan.md
    ├── step-03-vision-mission-review.md
    ├── step-04-strategic-options.md
    ├── step-05-philosophy-integration.md
    ├── step-06-priority-setting.md
    ├── step-07-resource-alignment.md
    └── step-08-execution-roadmap.md
```

## Coverage

- **Environmental Scan**: PESTLE, competitive, industry analysis
- **Vision/Mission Review**: Alignment, relevance, inspiration
- **Strategic Options**: Growth, diversification, focus strategies
- **Philosophy Integration**: Multiple strategic viewpoints
- **Priority Setting**: Focus areas, sequencing, trade-offs
- **Resource Alignment**: Budget, talent, capabilities
- **Execution Roadmap**: Milestones, metrics, accountability

## Strategic Philosophies Applied

- **Sun Tzu**: Strategic positioning, competitive advantage
- **Clausewitz**: Concentration of force, decisive points
- **Porter**: Competitive strategy, value chain
- **Blue Ocean**: Market creation, differentiation
- **McKinsey 7S**: Organizational alignment
- **Balanced Scorecard**: Multi-dimensional measurement
