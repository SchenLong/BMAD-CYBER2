# Pattern of Life

**Behavioral analysis and prediction through multi-source pattern analysis**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Behavioral Analysis |
| **Duration** | ~60 minutes |
| **Steps** | 4 |
| **Primary Agent** | Echo (Social Media Analyst) |
| **Supporting Agents** | Atlas, Sigil, Specter |

## Purpose

Build comprehensive behavioral profile through multi-source pattern analysis for prediction and operational planning:
- Digital behavior patterns
- Physical movement patterns
- Communication patterns
- Operational assessment

## Steps

1. **Digital Behavior Patterns** (Echo) - Posting time analysis, platform usage, content themes
2. **Physical Movement Patterns** (Atlas) - Location check-ins, photo geolocation, travel patterns
3. **Communication Patterns** (Sigil) - Active hours, communication frequency, contact network
4. **Operational Assessment** (Specter) - Predictable vulnerabilities, surveillance windows

## Outputs

- Weekly routine matrix
- Location heat map
- Social graph with activity
- Predictive timeline
- Operational windows
- Anomaly baseline
