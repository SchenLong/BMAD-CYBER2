# Cybersec Team Module

Offensive and defensive cybersecurity operations. 15 agents and 13 workflows
covering penetration testing, compliance, incident response, and security architecture.

## Workflows

| Command | Description | When to Use |
|---------|-------------|-------------|
| `/threat-modeling` | STRIDE-based threat modeling | Starting a new system design or reviewing existing |
| `/vulnerability-management` | End-to-end vulnerability lifecycle | Tracking and remediating discovered vulnerabilities |
| `/incident-response-playbook` | NIST-aligned incident response | Building or executing IR procedures |
| `/web-app-security-testing` | OWASP web app penetration testing | Testing web applications for common vulns |
| `/cloud-security-assessment` | Cloud IAM, network, data security review | Reviewing AWS/GCP/Azure configurations |
| `/network-assessment` | Network penetration testing | Evaluating network perimeter and internals |
| `/compliance-audit-prep` | Multi-framework compliance audit prep | Preparing for SOC2, ISO 27001, PCI-DSS audits |
| `/security-architecture-review` | Zero-Trust architecture review | Evaluating or designing security architecture |
| `/infrastructure-security-testing` | Server, container, and CI/CD security | Hardening infrastructure and pipelines |
| `/mobile-security-testing` | iOS and Android app security | Testing mobile applications |
| `/blockchain-security-assessment` | Smart contract and blockchain audit | Reviewing blockchain implementations |
| `/security-awareness-training` | Security awareness program development | Building training programs for staff |
| `/virtual-ciso-consulting` | vCISO strategic planning and governance | Executive-level security guidance |

## Key Agents

- **penetration-tester** -- Offensive security testing specialist
- **security-architect** -- Zero-Trust and defense-in-depth design
- **incident-commander** -- Incident response coordination
- **soc-analyst** -- Security operations center monitoring
- **threat-analyst** -- Threat landscape analysis
- **compliance-guardian** -- Regulatory compliance oversight
- **forensic-investigator** -- Digital forensics and evidence handling
- **cloud-security-specialist** -- Cloud-native security
- **blue-team-lead** -- Defensive operations coordination

## Quick Start

Run a threat model for your current project:

    /threat-modeling

Prepare for an upcoming compliance audit:

    /compliance-audit-prep

Review cloud security posture:

    /cloud-security-assessment

For more details: `/bmad-help search security`
