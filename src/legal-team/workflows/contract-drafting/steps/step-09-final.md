# Step 9: Final Draft Generation

## STEP GOAL

Generate the complete contract document with explanatory commentary.

## EXECUTION SEQUENCE

### 1. Compile Contract

Assemble all sections into final contract:

- Proper formatting
- Complete structure
- All provisions included

### 2. Add Commentary

Create separate commentary document explaining:

- Key provisions and their purpose
- Negotiation points
- Alternative language options
- Jurisdiction-specific notes

### 3. Generate Final Output

Create two documents:

**Contract Document:**

```markdown
# [CONTRACT TITLE]

**Parties:**
[Party details]

**Effective Date:** _______________

---

[Full contract text organized by section]

---

**IN WITNESS WHEREOF**, the parties have executed this Agreement as of the date first written above.

[Signature blocks]
```

**Commentary Document:**

```markdown
# Contract Commentary: [Type]

## Overview
[Brief summary]

## Key Provisions Explained
[Section-by-section notes]

## Negotiation Guidance
[Points to consider]

## Legal Disclaimer
**DISCLAIMER:** This contract draft is provided for informational purposes only and does not constitute legal advice. Review by qualified legal counsel is recommended before execution.

*Generated by Legal Team Module - Contract Drafting Workflow*
*Drafted by: Covenant (Contract Specialist)*
```

Update frontmatter:

- `stepsCompleted: [1, 2, 3, 4, 5, 6, 7, 8, 9]`
- `status: "completed"`

### 4. Present Completion

"Your contract draft is complete!"

Present:

- Contract summary
- Key features
- Recommended next steps

### 5. Final Menu

**[D]** Download contract | **[R]** Request review by specialist | **[N]** Start negotiation prep | **[E]** Exit

- IF R: Route to contract-review workflow
- IF N: Load negotiation strategy prompt
- IF E: Conclude session
