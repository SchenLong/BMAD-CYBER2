# Legal Matter Intake Workflow

## Purpose
Initial case assessment and routing workflow that serves as the entry point for all legal matters.

## Type
Interactive

## Primary Users
All users (business owners, individuals, in-house counsel)

## Key Outputs
- Matter brief with complete situation summary
- Jurisdiction determination
- Appropriate specialist agent assignment
- Recommended workflow routing

## Workflow Steps (Planned)
1. Welcome and context gathering
2. Matter type classification
3. Jurisdiction identification
4. Urgency assessment
5. Party role determination
6. Initial document/evidence review
7. Specialist routing recommendation
8. Next steps guidance

## Agents Involved
- Counsel (primary - directs the intake)
- Jurisdiction specialists consulted as needed

## Integration Points
- Routes to Contract Review, Contract Drafting, Corporate Formation, Dispute Strategy, or Tax Planning workflows
- May trigger Cross-Border Matter workflow for multi-jurisdiction issues
