# Operation Mosaic

**Full spectrum target package using all 11 agents in coordinated intelligence collection and analysis**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Flagship / Comprehensive |
| **Duration** | 2-4 hours |
| **Steps** | 9 |
| **Primary Agent** | Vector (OSINT Lead) |
| **All Agents** | Vector, Resolver, Echo, Shadow, Proxy, Probe, Atlas, Dossier, Viper |

## Purpose

Complete intelligence package on any target (person, organization, infrastructure) using all available INT disciplines in coordinated sequence:

- Comprehensive organizational assessments
- High-stakes due diligence
- Threat actor profiling
- Full-spectrum target packages

## Steps

1. **Target Definition & Collection Planning** (Vector) - Requirements, collection plan, tasking
2. **Digital Footprint** (Resolver + Probe) - Domain/IP recon, infrastructure mapping
3. **Social Presence** (Echo) - Platform enumeration, account correlation
4. **Dark Web Exposure** (Shadow) - Breach checks, forum mentions, credentials
5. **Corporate Intelligence** (Proxy) - Entity structure, financials, relationships
6. **Geospatial Analysis** (Atlas) - Location intelligence, pattern of life
7. **Threat Correlation** (Dossier) - Actor attribution, TTP analysis
8. **HUMINT Assessment** (Viper) - Approach vectors, relationship mapping
9. **Intelligence Fusion** (Vector) - Multi-INT synthesis, final package

## Outputs

- Comprehensive target dossier
- Multi-source corroborated findings
- Risk and threat assessment
- Recommended actions

/intel-team:osint-lead
