# Infrastructure Genealogy

**Infrastructure ownership history and evolution tracking**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Technical Intelligence |
| **Duration** | 1-2 hours |
| **Steps** | 5 |
| **Primary Agent** | Resolver (Domain Intel) |
| **Supporting Agents** | Probe, Proxy, Shadow, Dossier |

## Purpose

Trace infrastructure ownership and changes over time:

- Domain ownership history
- IP allocation tracking
- Hosting provider changes
- Infrastructure attribution

## Steps

1. **Ownership Archaeology** (Resolver) - WHOIS history, registrant tracking
2. **Technical Evolution** (Probe) - IP history, technology changes
3. **Corporate Ownership** (Proxy) - Entity ownership chain
4. **Underground Connections** (Shadow) - Abuse history, threat correlation
5. **Threat Timeline** (Dossier) - Attribution and timeline synthesis

## Outputs

- Infrastructure genealogy report
- Ownership timeline
- Attribution assessment
- Diamond Model analysis
