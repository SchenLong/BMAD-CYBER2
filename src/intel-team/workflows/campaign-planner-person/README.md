# Campaign Planner - Person

**Full intelligence campaign planning and execution against individual targets**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Individual Investigation |
| **Duration** | 1-2 hours |
| **Steps** | 5 |
| **Primary Agent** | Vector (OSINT Lead) |
| **Supporting Agents** | Resolver, Echo, Shadow, Probe, Atlas |

## Purpose

Structured intelligence collection campaign against an individual:

- Person of interest investigations
- Background investigations
- Threat actor attribution
- Due diligence on individuals

## Steps

1. **Target Profile** (Vector) - Identity validation, collection requirements
2. **Pivot Mapping** (Resolver) - Digital infrastructure connections
3. **Social Footprint** (Echo) - Social media presence analysis
4. **Exposure Assessment** (Shadow) - Dark web exposure check
5. **Campaign Synthesis** (Vector) - Findings integration, assessment

## Outputs

- Individual target dossier
- Digital footprint map
- Exposure and risk assessment
- Relationship network

## Usage

```
/intel-team:osint-lead
> Campaign Planner - Person
```
