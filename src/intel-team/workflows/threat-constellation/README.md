# Threat Constellation

**Threat actor ecosystem mapping**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Threat Intelligence |
| **Duration** | 2-3 hours |
| **Steps** | 5 |
| **Primary Agent** | Dossier (Threat Actor Profiler) |
| **Supporting Agents** | Shadow, Resolver, Probe, Echo |

## Purpose

Map the complete ecosystem around a threat actor:

- Actor relationship mapping
- Infrastructure clustering
- Campaign correlation
- Evolution tracking

## Steps

1. **Actor Profile** (Dossier) - Known actor documentation
2. **Infrastructure Cluster** (Resolver) - Related infrastructure discovery
3. **Underground Network** (Shadow) - Forum/marketplace connections
4. **Tooling Analysis** (Probe) - Shared tools and malware
5. **Ecosystem Synthesis** (Dossier) - Complete constellation map

## Outputs

- Threat actor ecosystem map
- Relationship network
- Infrastructure cluster analysis
- Campaign timeline

## Usage

```
/intel-team:threat-actor-profiler
> Threat Constellation
```

See [workflow.md](workflow.md) for detailed step instructions.
