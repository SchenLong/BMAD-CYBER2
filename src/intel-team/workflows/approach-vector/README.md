# Approach Vector

**HUMINT operation planning for target engagement**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Operational Planning |
| **Duration** | ~60 minutes |
| **Steps** | 4 |
| **Primary Agent** | Viper (HUMINT Specialist) |
| **Supporting Agents** | Echo, Atlas, Specter |

## Purpose

Plan human intelligence approach to target:

- Psychological vulnerability identification (MICE framework)
- Social entry point mapping
- Physical access analysis
- Cover story development

## Steps

1. **Target Assessment** (Viper) - MICE analysis, vulnerability identification, recruitment potential
2. **Social Entry Point Mapping** (Echo) - Social network analysis, interests, events, communities
3. **Physical Access Analysis** (Atlas) - Location patterns, frequented venues, travel patterns
4. **Approach Planning** (Specter) - Cover story development, risk assessment, contingencies

## Outputs

- Target psychological profile
- Approach vectors (ranked by feasibility)
- Cover story package
- Risk assessment matrix
- Contingency plans
- Social entry point map
- Physical access windows

```
/intel-team:humint-specialist
> Approach Vector
```
