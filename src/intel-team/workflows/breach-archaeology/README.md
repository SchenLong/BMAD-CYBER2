# Breach Archaeology

**Historical breach and exposure analysis**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Technical Intelligence |
| **Duration** | 45-60 minutes |
| **Steps** | 4 |
| **Primary Agent** | Shadow (Dark Web Analyst) |
| **Supporting Agents** | Probe, Resolver, Echo |

## Purpose

Comprehensive breach and data exposure history:
- Credential exposure assessment
- Breach database analysis
- Historical leak identification
- Exposure timeline construction

## Steps

1. **Target Setup** (Shadow) - Identifier validation, search preparation
2. **Breach Database Search** (Shadow) - HIBP, breach databases
3. **Paste Site Analysis** (Shadow + Probe) - Paste/dump discovery
4. **Exposure Synthesis** (Shadow) - Timeline and risk assessment

## Outputs

- Breach exposure report
- Credential exposure inventory
- Exposure timeline
- Risk assessment

## Usage

```
/intel-team:dark-web-analyst
> Breach Archaeology
```

See [workflow.md](workflow.md) for detailed step instructions.
