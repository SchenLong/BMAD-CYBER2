# The Synthesis

**Multi-source intelligence fusion for unified assessments**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | All-Source Fusion |
| **Duration** | ~60 minutes |
| **Steps** | 4 |
| **Primary Agent** | Vector (OSINT Lead) |
| **Supporting Agents** | All intelligence agents (for conflict resolution) |

## Purpose

Take multiple intelligence inputs and produce unified all-source intelligence product:
- Correlate findings across sources
- Resolve conflicts between assessments
- Assess confidence levels
- Produce unified assessment

## Steps

1. **Input Cataloging** (Vector) - Inventory sources, assess reliability, identify overlaps
2. **Correlation Analysis** (Vector) - Cross-reference findings, identify corroboration
3. **Confidence Assessment** (Vector) - Apply confidence framework, document evidence basis
4. **Product Assembly** (Vector) - Executive summary, key findings, recommendations

## Outputs

- Intelligence assessment (formal product)
- Evidence matrix
- Confidence breakdown
- Dissenting views
- Collection recommendations

/intel-team:osint-lead
> The Synthesis
