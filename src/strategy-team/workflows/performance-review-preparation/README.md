# Performance Review Preparation Workflow

## Overview

A comprehensive 6-step workflow for preparing executive performance reviews. Helps leaders develop balanced assessments, calibrate feedback for fairness, prepare for difficult conversations, and create development-focused reviews that drive growth and engagement.

## Workflow Structure

```
performance-review-preparation/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-performance-assessment.md
    ├── step-03-feedback-calibration.md
    ├── step-04-development-planning.md
    ├── step-05-conversation-prep.md
    └── step-06-review-document.md
```

## Coverage

- **Review Setup**: Context, inputs, objectives, review framework
- **Performance Assessment**: Results, behaviors, impact evaluation
- **Feedback Calibration**: Balance, fairness, bias check
- **Development Planning**: Growth areas, development actions
- **Conversation Preparation**: Difficult feedback, anticipating reactions
- **Review Documentation**: Complete review materials
