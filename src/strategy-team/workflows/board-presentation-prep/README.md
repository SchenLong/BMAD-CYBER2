# Board Presentation Prep Workflow

## Overview

A structured 7-step workflow for preparing compelling board presentations. Combines strategic messaging with comprehensive Q&A preparation to ensure executives can effectively communicate with board members and stakeholders.

## Workflow Structure

```
board-presentation-prep/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-audience-analysis.md
    ├── step-03-narrative-structure.md
    ├── step-04-evidence-compilation.md
    ├── step-05-visual-design.md
    ├── step-06-qa-preparation.md
    └── step-07-final-review.md
```

## Coverage

- **Audience Analysis**: Board composition, priorities, concerns
- **Narrative Structure**: Story arc, key messages, call-to-action
- **Evidence Compilation**: Data points, benchmarks, case studies
- **Visual Design**: Slide structure, data visualization
- **Q&A Preparation**: Anticipated questions, difficult scenarios
- **Final Review**: Rehearsal, timing, refinement

## Related Agents

- **Giuseppe** (Communications Director): Messaging strategy
- **Augustus** (Policy Analyst): Evidence-based arguments
- **Cicero** (Debate Coach): Argumentation and rhetoric
