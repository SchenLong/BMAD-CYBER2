# Stakeholder Negotiation Prep Workflow

## Overview

An 8-step workflow for preparing comprehensive negotiation playbooks. Helps executives prepare for critical negotiations with stakeholder analysis, strategy development, and scenario planning.

## Workflow Structure

```
stakeholder-negotiation-prep/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-stakeholder-analysis.md
    ├── step-03-interest-mapping.md
    ├── step-04-batna-analysis.md
    ├── step-05-strategy-development.md
    ├── step-06-scenario-planning.md
    ├── step-07-tactical-preparation.md
    └── step-08-playbook-compilation.md
```

## Coverage

- **Stakeholder Analysis**: Counterpart profile, motivations, constraints
- **Interest Mapping**: Underlying interests vs. stated positions
- **BATNA Analysis**: Best alternatives for both parties
- **Strategy Development**: Approach, opening, concessions
- **Scenario Planning**: Best/worst/likely outcomes
- **Tactical Preparation**: Specific responses, walk-away points
- **Playbook Compilation**: Complete negotiation guide

## Negotiation Types

- Contract negotiations
- Partnership agreements
- M&A discussions
- Labor negotiations
- Vendor/supplier deals
- Internal resource allocation
- Regulatory negotiations
