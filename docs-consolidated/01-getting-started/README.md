## 🚀 Quick Start Options

### Option 1: Demo Environment (Recommended for First Time)
```bash
# Clone and run demo
git clone https://github.com/your-org/bmad-cyber2
cd bmad-cyber2
npm run demo
```

### Option 2: Docker Quick Start
```bash
# Run with Docker
docker run -p 3000:3000 bmad/cybercommand:latest
```

### Option 3: NPM Installation
```bash
# Install via NPM
npm install -g @bmad/cybercommand
bmad init
```
