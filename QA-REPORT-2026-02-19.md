## Bugs Found

### 1. Prisma Binary Mismatch (CRITICAL) - FIXED

**Description:** Prisma Client was compiled for `darwin-arm64` (Mac) but the server runs on `debian-openssl-3.0.x` (Linux).

**Error Message:**
```
Prisma Client could not locate the Query Engine for runtime "debian-openssl-3.0.x"
```

**Fix Applied:**
Updated `prisma/schema.prisma`:
```prisma
generator client {
  provider      = "prisma-client-js"
  binaryTargets = ["native", "debian-openssl-3.0.x"]
}
```

Then ran `npx prisma generate` and `npx prisma db push`.

**Status:** FIXED

---

### 2. Password Complexity Weak (MEDIUM)

**Description:** Passwords consisting of repeated characters (e.g., `aaaaaaaaaaaa`) are accepted despite meeting minimum length.

**Impact:** Users can create weak passwords that are vulnerable to brute force attacks.

**Recommendation:** Add complexity requirements:
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character

**Location:** `apps/web-ui/src/lib/auth/validation.ts` or equivalent

## Additional Findings

### Registration JSON Parsing Error

When registering with passwords containing special characters (like `!`), the registration fails with:
```
Registration error: SyntaxError: Bad escaped character in JSON
```

This appears to be a backend parsing issue in the registration endpoint.

**Workaround:** Use passwords without special characters
