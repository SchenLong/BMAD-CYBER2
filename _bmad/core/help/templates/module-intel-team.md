# Intel Team Module

Intelligence collection and analysis operations. 11 agents and 19 workflows
spanning OSINT, HUMINT, SIGINT, counter-intelligence, and threat actor profiling.

## Workflows

| Command | Description | When to Use |
|---------|-------------|-------------|
| `/flash-assessment` | Rapid 15-minute OSINT triage | Quick initial reconnaissance on a target |
| `/operation-mosaic` | Full spectrum coordinated intel package | Comprehensive multi-source investigation |
| `/spider-web` | Network mapping and expansion | Mapping relationships and connections |
| `/breach-archaeology` | Data exposure assessment across breaches | Checking for leaked credentials or data |
| `/campaign-planner-org` | OSINT campaign for organizations | Structured org-level intelligence gathering |
| `/campaign-planner-person` | OSINT campaign for individuals | Person-of-interest investigation planning |
| `/campaign-ai` | OSINT campaign for AI systems/entities | Investigating AI platforms and actors |
| `/threat-constellation` | Map threat actor ecosystem | Understanding adversary relationships |
| `/pattern-of-life` | Behavioral analysis and prediction | Building behavioral profiles |
| `/attribution-chain` | Evidence-based attribution analysis | Linking activity to specific actors |
| `/digital-necromancy` | Recover deleted digital presence | Finding archived or removed content |
| `/doppelganger-hunt` | Identify fake accounts and impersonators | Detecting impostor accounts |
| `/counter-intel-audit` | Internal exposure and OPSEC assessment | Evaluating your own attack surface |
| `/infrastructure-genealogy` | Trace digital infrastructure history | Mapping domain/IP ownership over time |
| `/signal-landscape` | SIGINT opportunity mapping | Identifying signals intelligence sources |
| `/approach-vector` | HUMINT operation planning | Planning human source engagement |
| `/ground-truth` | Field operation preparation package | Preparing for physical-world operations |
| `/tripwire` | Alerting and monitoring configuration | Setting up ongoing monitoring |
| `/the-synthesis` | Multi-source intelligence fusion | Combining intel from multiple sources |

## Key Agents

- **osint-lead** -- Open source intelligence coordination
- **dark-web-analyst** -- Dark web monitoring and research
- **threat-actor-profiler** -- Adversary characterization
- **social-media-analyst** -- Social platform analysis
- **humint-specialist** -- Human intelligence operations
- **sigint-specialist** -- Signals intelligence collection
- **geospatial-analyst** -- Location and spatial analysis
- **technical-researcher** -- Technical infrastructure research

## Quick Start

Start a rapid assessment on a target:

    /flash-assessment

Launch a comprehensive investigation:

    /operation-mosaic

Check for breach exposure:

    /breach-archaeology

For more details: `/bmad-help search intel`
