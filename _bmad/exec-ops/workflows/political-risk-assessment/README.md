# Political Risk Assessment Workflow

## Overview

A 7-step workflow for evaluating political risks in strategic decisions and initiatives. Provides systematic analysis of internal and external political factors that could impact organizational success.

## Workflow Structure

```
political-risk-assessment/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-context-analysis.md
    ├── step-03-stakeholder-assessment.md
    ├── step-04-risk-identification.md
    ├── step-05-impact-analysis.md
    ├── step-06-mitigation-strategies.md
    └── step-07-monitoring-plan.md
```

## Coverage

- **Context Analysis**: Political environment, power structures, trends
- **Stakeholder Assessment**: Key players, interests, influence
- **Risk Identification**: Internal and external political risks
- **Impact Analysis**: Probability, severity, timing
- **Mitigation Strategies**: Prevention, response, adaptation
- **Monitoring Plan**: Early warning indicators, trigger events

## Risk Categories

- Regulatory/policy changes
- Leadership transitions
- Stakeholder opposition
- Coalition instability
- Reputation threats
- Resource allocation shifts
- External political events
