# Corporate Political Game Workflow

## Overview

A strategic 9-step workflow for navigating internal corporate politics. Provides comprehensive political strategy for executives dealing with organizational power dynamics, stakeholder management, and influence building.

## Workflow Structure

```
corporate-political-game/
├── workflow.md
├── README.md

    ├── step-01-init.md
    ├── step-01b-continue.md

    ├── step-06-coalition-building.md
    ├── step-07-opposition-management.md
    ├── step-08-execution-tactics.md
    └── step-09-political-maintenance.md
```

## Coverage

- **Power Mapping**: Formal and informal power structures
- **Alliance Analysis**: Allies, opponents, fence-sitters
- **Political Landscape**: Decision-making processes, gatekeepers
- **Influence Strategy**: Persuasion, coalition, leverage
- **Coalition Building**: Shared interests, mutual benefits
- **Opposition Management**: Neutralization, conversion, isolation
- **Political Maintenance**: Relationship cultivation, reputation
