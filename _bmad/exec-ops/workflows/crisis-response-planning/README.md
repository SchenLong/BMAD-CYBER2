# Crisis Response Planning Workflow

## Overview

A 7-step workflow for developing crisis communication and response strategies. Helps executives prepare for and manage organizational crises with structured planning and rapid response capabilities.

## Workflow Structure

```
crisis-response-planning/
├── workflow.md
├── README.md
└── steps/
    ├── step-01-init.md
    ├── step-01b-continue.md
    ├── step-02-crisis-assessment.md
    ├── step-03-stakeholder-impact.md
    ├── step-04-communication-strategy.md
    ├── step-05-response-actions.md
    ├── step-06-resource-mobilization.md
    └── step-07-recovery-planning.md
```

## Coverage

- **Crisis Assessment**: Type, severity, timeline, escalation
- **Stakeholder Impact**: Affected parties, concerns, expectations
- **Communication Strategy**: Messaging, channels, timing, spokesperson
- **Response Actions**: Immediate, short-term, long-term actions
- **Resource Mobilization**: Team, budget, external support
- **Recovery Planning**: Reputation repair, process improvement

## Crisis Types Addressed

- Reputational crises
- Operational failures
- Leadership crises
- Financial emergencies
- Legal/regulatory issues
- Public relations incidents
- Cybersecurity incidents
