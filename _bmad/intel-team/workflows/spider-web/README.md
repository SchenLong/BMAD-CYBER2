# Spider Web

**Network relationship mapping and affiliation analysis**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Organization Investigation |
| **Duration** | 1-2 hours |
| **Steps** | 4 |
| **Primary Agent** | Proxy (Corporate Intel) |
| **Supporting Agents** | Resolver, Echo, Dossier |

## Purpose

Map relationship networks and affiliations:
- Corporate relationship mapping
- Beneficial ownership chains
- Influence network analysis
- Hidden connection discovery

## Steps

1. **Seed Analysis** (Proxy) - Initial entity analysis
2. **Expansion** (Resolver + Echo) - Network node discovery
3. **Correlation** (Dossier) - Relationship validation
4. **Network Synthesis** (Vector) - Complete network map

## Outputs

- Network relationship diagram
- Entity connection matrix
- Influence mapping
- Hidden relationship report

## Usage

```
/intel-team:corporate-intel-specialist
> Spider Web
```
