# Campaign AI

**OSINT campaign planning for AI systems, models, and companies**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Campaign Planning / Emerging Tech |
| **Duration** | ~120 minutes |
| **Steps** | 8 |
| **Primary Agent** | Vector (OSINT Lead) |
| **Supporting Agents** | Probe, Resolver, Proxy, Echo, Shadow, Dossier |

## Purpose

Specialized OSINT campaign planning targeting AI entities:
- AI companies and startups
- AI models and capabilities
- AI applications and infrastructure
- AI researchers and personnel

## Steps

1. **Campaign Initialization** (Vector) - AI-specific intelligence requirements
2. **Technical Intelligence** (Probe) - Model analysis, infrastructure, code research
3. **Digital Infrastructure** (Resolver) - Domains, API endpoints, cloud footprint
4. **Corporate Structure & Funding** (Proxy) - Entity verification, investment, regulatory
5. **Personnel & Organization** (Echo) - Key personnel, organization analysis
6. **Underground & Exposure** (Shadow) - Credential exposures, leaks
7. **Threat & Risk Assessment** (Dossier) - Nation-state interest, competitive threats
8. **Campaign Plan Assembly** (Vector) - Final profile, monitoring plan

## Outputs

- AI entity campaign plan
- Technical capability assessment
- Model profile
- Organization map
- Key personnel dossiers
- Infrastructure analysis
- Vulnerability assessment
- Competitive positioning matrix
- Monitoring recommendations
