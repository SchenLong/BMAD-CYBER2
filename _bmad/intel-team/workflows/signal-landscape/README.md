# Signal Landscape

**SIGINT opportunity mapping and communications analysis**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Technical Intelligence |
| **Duration** | 1-2 hours |
| **Steps** | 4 |
| **Primary Agent** | Sigil (SIGINT Specialist) |
| **Supporting Agents** | Probe, Resolver, Atlas |

## Purpose

Map communications infrastructure and signal opportunities:
- Communications infrastructure mapping
- Protocol identification
- Vulnerability assessment
- SIGINT collection planning

## Steps

1. **Communications Mapping** (Sigil) - Channel identification, protocol analysis
2. **Technical Vulnerability** (Probe) - Encryption assessment, weaknesses
3. **Infrastructure Signals** (Resolver) - DNS/network signal analysis
4. **Geographic Mapping** (Atlas) - Signal geographic correlation

## Outputs

- Communications landscape map
- Signal opportunity assessment
- Vulnerability identification
- Collection recommendations

## Usage

```
/intel-team:sigint-specialist
> Signal Landscape
```

See [workflow.md](workflow.md) for detailed step instructions.
