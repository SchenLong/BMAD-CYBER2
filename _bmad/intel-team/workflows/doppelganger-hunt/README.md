# Doppelganger Hunt

**Behavioral pattern analysis and identity verification for fake account detection**

## Overview

| Attribute | Value |
|-----------|-------|
| **Classification** | Individual Investigation |
| **Duration** | 45-60 minutes |
| **Steps** | 4 |
| **Primary Agent** | Echo (Social Media Analyst) |
| **Supporting Agents** | Probe, Atlas, Viper |

## Purpose

Detect and analyze fake, impersonation, or sock puppet accounts:
- Impersonation detection
- Sock puppet identification
- Bot account analysis
- Identity verification
- Influence operation detection

## Steps

1. **Behavioral Analysis** (Echo) - Posting patterns, engagement analysis
2. **Technical Analysis** (Probe) - Image forensics, metadata analysis
3. **Location Analysis** (Atlas) - Geographic consistency verification
4. **Psychological Assessment** (Viper) - Persona consistency, motivation

## Outputs

- Authenticity assessment score
- Behavioral anomaly report
- True identity hypothesis (if fake)
- Evidence documentation

## Usage

```
/intel-team:social-media-analyst
> Doppelganger Hunt
```

See [workflow.md](workflow.md) for detailed step instructions.
