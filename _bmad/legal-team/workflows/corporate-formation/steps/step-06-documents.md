# Step 6: Document Requirements

## STEP GOAL

Compile complete list of documents required for entity formation.

## EXECUTION SEQUENCE

### 1. Document Checklist by Jurisdiction

**USA LLC (Example - Delaware):**
- [ ] Certificate of Formation
- [ ] Operating Agreement
- [ ] EIN Application (SS-4)
- [ ] Initial Resolutions
- [ ] Registered Agent Agreement
- [ ] Member Certificates (optional)
- [ ] Banking Resolution
- [ ] Beneficial Ownership Information (BOI) Report

**USA Corporation (Example - Delaware):**
- [ ] Certificate of Incorporation
- [ ] Bylaws
- [ ] Organizational Resolutions
- [ ] Stock Certificates
- [ ] Stock Ledger
- [ ] EIN Application
- [ ] S-Corp Election (Form 2553) if applicable
- [ ] BOI Report

**Spain SL:**
- [ ] Certificación Negativa de Denominación
- [ ] Escritura de Constitución
- [ ] Estatutos Sociales
- [ ] NIF Provisional
- [ ] Inscripción Registro Mercantil
- [ ] Alta en Hacienda (Modelo 036/037)
- [ ] Alta Seguridad Social (if applicable)
- [ ] Licencias municipales (if applicable)

**Estonia OÜ:**
- [ ] Company registration application
- [ ] Articles of Association
- [ ] Shareholder agreement (if multiple)
- [ ] Board member consent
- [ ] Registry code application
- [ ] VAT registration (if applicable)
- [ ] e-Business Register account

### 2. Personal Documents Required

**From Owners/Directors:**
- Passport or national ID (certified copy)
- Proof of address (utility bill, bank statement)
- Tax ID number (from residence country)
- Background information (some jurisdictions)
- Apostilled documents (for foreign use)

### 3. Third-Party Requirements

- Registered agent engagement
- Notarization (varies by jurisdiction)
- Apostille for foreign documents
- Certified translations (if applicable)
- Bank account opening documentation
