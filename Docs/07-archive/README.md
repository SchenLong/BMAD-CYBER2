# 07-Archive

This directory contains historical, deprecated, and archived documentation for the BMAD-CYBER2 project.

## Purpose

The archive section serves as a repository for documentation that is no longer actively maintained but may still hold historical value or serve as reference material for understanding the evolution of the project.

## Directory Structure

### `/legacy-documents/`
Contains outdated documentation from earlier project phases that has been superseded by current documentation. These documents are preserved for historical reference and to understand past design decisions.

### `/test-archives/`
Stores archived test reports, testing logs, and validation records from completed testing cycles. Useful for auditing purposes and understanding historical test coverage.

### `/archived-versions/`
Contains previous versions of documentation that has been significantly revised. Maintains version history for compliance and reference purposes.

### `/learning-documentation/`
Houses lessons learned documents, retrospectives, and knowledge capture from past development cycles. Valuable for onboarding and avoiding repeated mistakes.

## Guidelines

1. **Do not delete** - Move documents here instead of deleting them
2. **Date prefix** - When archiving, consider adding a date prefix (e.g., `2024-01-archive-filename.md`)
3. **Maintain structure** - Keep related documents organized in appropriate subdirectories
4. **Reference only** - Documents here should not be used as current guidance without verification

## Note

If you are looking for current, active documentation, please refer to the main documentation sections in `/docs/`. This archive is for reference purposes only.
